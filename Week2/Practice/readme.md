#this code contains of:
 --Show Text Button (button_label): Clicking this button updates the display label to show the text.
 --Clear Button (clearlabel): Clicking this button clears the text from the display label.
 --Close Button (closeform): Clicking this button closes the application window. 
 --Display Label: Displays the text when the show text button is clicked, and is cleared when the clear button is clicked.  
 --Image Box: Serves as a graphical placeholder element within the user interface window alongside the buttons and text label.
