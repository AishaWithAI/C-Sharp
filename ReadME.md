## Course Description
C# is a modern, object-oriented programming language used to build desktop applications, web applications, games, and other software.

## Course Objectives
1. This course incorporates the basic concepts of C# programming, problem solving and programming logic, as well as the design techniques of an object-oriented, event-driven language.
2. A high priority is given to writing applications that are easy for the user to understand and to use.
3. The course is rich in concise, practical, and real-world example programs, so the student not only learns how to use the various controls, constructs, and features of Visual C#, but also learns why and when to use them.

## Learning Outcomes

After completing the course, students should be able to:

1. Understand Windows and event-driven programming.
2. Develop GUI applications.
3. Apply programming logic when solving problems.
4. Use C# programming structures correctly.
5. Use methods to organize programs.
6. Work with arrays and lists.
7. Connect applications to databases using ADO.NET.
8. Develop small- to medium-sized Windows applications.
